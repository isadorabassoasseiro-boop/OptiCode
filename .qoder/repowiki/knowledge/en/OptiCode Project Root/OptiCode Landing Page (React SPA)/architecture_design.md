Entry point is `index.html`, which mounts a `<div id="root">` and loads `/src/main.jsx` as an ES module. `main.jsx` bootstraps React via `react-dom/client`'s `createRoot` inside `StrictMode` and renders the top-level `App` component. `App.jsx` is a pure layout orchestrator that composes eight sibling sections (`Header`, `Hero`, `Solucao`, `PublicoAlvo`, `Galeria`, `Equipe`, `Contato`, `Footer`) with no shared state or routing — each section lives in its own file under `src/components/`. Some sections are further split into presentational cards/columns (e.g. `SolucaoCard`, `PublicoAlvoCard`, `EquipeCard`, `GaleriaFotos`, `FooterColuna`, `FooterLink`, `HeaderLink`, `HeroBenefico`, `ContatoItem`, `ContatoForm`). Styling is scoped per-component via separate `.css` files imported alongside each JSX file; global resets live in `src/index.css` and app-wide styles in `src/App.css`. There is no build tooling visible at this scope — the project relies on Vite's native ESM support for JSX.
