The root is a flat Vite workspace with no additional child services — it only configures the build toolchain consumed by the frontend_app child. `vite.config.js` registers the `@vitejs/plugin-react` and `@tailwindcss/vite` plugins so the React SPA can use JSX and Tailwind classes. `package.json` declares the four entry scripts (`dev`, `build`, `lint`, `preview`) that all delegate to Vite or ESLint; there is no cross-child orchestration beyond this shared configuration surface.
